Smart Weather Dashboard

This project is an interactive weather dashboard built using Python and Streamlit. The application allows users to search for real-time weather information by entering the name of a city. It connects to a weather API to retrieve current weather data and displays the results through an easy-to-use web interface.

The dashboard processes the weather data received from the API and presents important information such as temperature, humidity, and weather conditions. Streamlit is used to create a simple and interactive interface that allows users to quickly access weather details without needing complex setup or configuration.

This project demonstrates how Python can be used to build lightweight web applications that interact with external APIs and present real-time data in a user-friendly format.

Live App:
https://smart-weather-dashboard-uvwmvqtbfb4tw7syf9zzk5.streamlit.app/

Components:
- City name input field for searching weather information
- API integration for retrieving real-time weather data
- Display of key weather details such as temperature, humidity, and conditions
- Interactive dashboard interface built using Streamlit

Technologies Used:
Python, Streamlit, Requests, JSON, Weather API
